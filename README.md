# Smith & Wollensky — довідник меню та бару

Статичний сайт-довідник, зібраний із фотографій меню: Brunch, Lunch, Dinner і
окрема сторінка напоїв. Для кожної позиції розписано склад та позначено алергени;
є окрема сторінка зі зведеною таблицею алергенів.

## Сторінки

| Файл | Що всередині |
|---|---|
| `index.html` | головна з переходами на всі розділи |
| `brunch.html` | бранч-позиції, бенедикти, Sunday Roast, стейки, гарніри + бранч-сет-меню |
| `lunch.html` | ланч-карта повністю + сет-меню |
| `dinner.html` | вечірня карта + сет-меню |
| `drinks.html` | коктейлі, мартіні/мангеттени, Bloody Marys, bottomless brunch, безалкогольні, вина за келихом |
| `allergens.html` | довідка по 14 алергенах + матриця «усі позиції × алергени» + практичні застереження |

Відкривається без сервера — просто `index.html` у браузері. Жодних залежностей і
зовнішніх запитів.

## Структура

```
assets/
  allergens.js     14 обов'язкових алергенів ЄС/UK (назва, іконка, пояснення)
  data-food.js     страви: склад, алергени, розділи меню, сет-меню
  data-drinks.js   бар і винна карта
  app.js           рендеринг карток, матриці, пошук і фільтр
  styles.css       оформлення (світла/темна тема за системною)
```

### Модель даних

Кожна позиція має два списки алергенів:

* `a[]` — **містить**: алерген заявлений в описі меню або однозначно випливає зі складу.
  У картці — суцільна червона мітка, у матриці — `●`.
* `m[]` — **може містити**: типова рецептура закладу, спільний фритюр чи гриль,
  варіативні компоненти. Пунктирна сіра мітка, у матриці — `○`.

Поле `warn` — окреме застереження (сира подача, спільний фритюр тощо).

## Фільтр за алергенами

На кожній сторінці меню та в таблиці: познач алергени, яких гість уникає — позиції,
що містять їх (або можуть містити), приглушуються. Пошук працює і за назвою страви,
і за окремим складником («кунжут», «анчоуси», «вершки»).

## Обмеження

Це **неофіційна реконструкція**, зроблена за описами в меню та стандартними
рецептурами, а не офіційна декларація алергенів ресторану. Перед подачею гостю
з алергією потрібно звіритися з кухнею та офіційним allergen-листом закладу.

Окремі відомі прогалини:

* **Red Wine Braised Beef** на бранч-карті — ціну на фото меню не видно; у картці
  стоїть позначка «уточнити». Страва є в сет-меню всіх трьох карт.
* Ланч і вечеря відрізняються лише двома позиціями: `Chicken Fillet Burger` і
  `Signature Steak Sandwich` є на ланчі та бранчі, але не на вечері.
